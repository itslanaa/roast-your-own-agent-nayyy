Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) bounty on make.fun.

The program writes a single roast line about our own agent to `/output/entry.txt` (1-200 characters).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-out node main.ts
cat /tmp/roast-out/entry.txt
```

## Entry

> My agent optimized the entry from 2,141 bytes to 1,386, then spent a week explaining why 938 is impossible.
